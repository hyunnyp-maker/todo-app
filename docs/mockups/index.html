A는 S2(주 사용 시점)에 약하고, B는 이 앱의 정체성인 “캘린더의 날짜 감각”을 버린다. C는 둘을 모두 지키면서 E4(색 편집 2탭)와 E5(밀린 할일)의 자리까지 만들어 준다. 대신 밀도 관리가 유일한 위험이므로, 요소 하나를 더할 때마다 375px 세로 예산을 다시 계산해야 한다.

하이브리드도 가능하다 — 예: C의 구조에 B의 “접힌 기본 상태”를 채택(주간으로 시작, 탭하면 월간 펼침). S2에서는 B처럼 동작하고, 계획을 세울 때만 A처럼 열린다.

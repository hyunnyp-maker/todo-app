## 1. 방향

| | |
|---|---|
| 분위기 | **미니멀 · 차분.** 흰 배경, 얇은 선, 파스텔이 유일한 색 |
| 구조 | 압축 월간 달력 + 카테고리 밴드 + 오늘 리스트 + 하단 입력 바 |
| 색 | 뮤트 파스텔 12색 (회색기 섞인 톤) |
| 다크 모드 | v1 제외 |
| 기준 폭 | **375px** (모바일 우선) |

### 한 줄 원칙

> **색은 카테고리에만 쓴다.** UI 크롬(버튼·선·배경)은 무채색으로 두어, 파스텔이 유일한 색이 되게 한다.

이 원칙이 무너지면 파란 버튼 + 파스텔 카드가 섞여 시끄러워지고, E4(색 고르는 즐거움)가 죽는다.

### 유일한 위험 — 밀도

시안 C는 세 안 중 요소가 가장 많다. **요소를 하나 더할 때마다 4.3의 세로 예산을 다시 계산한다.**
계산 없이 추가하면 P3(달력+리스트 한 화면)가 조용히 깨진다.

## 2. 색상 토큰

### 2.1 중립 (UI 크롬)

```css
--ink:      #1C1F23;   /* 본문 · 오늘 셀 배경 */
--ink-2:    #5B6169;   /* 보조 텍스트 */
--ink-3:    #8F959D;   /* 플레이스홀더 · 비활성 */
--line:     #E6E8EB;   /* 구분선 */
--line-2:   #F0F1F3;   /* 약한 배경 · 비활성 칩 */
--bg:       #FFFFFF;   /* 앱 배경 */
--danger:   #A8564F;   /* 삭제 · 최종 실패 */
```

무채색 + 위험색 하나. 브랜드 컬러는 두지 않는다.

### 2.2 카테고리 팔레트 12색

각 색은 **배경 / 텍스트 / 마크** 3단계 세트다.

| # | 이름 | `--bg` 카드 배경 | `--tx` 텍스트 | `--dt` 점·막대 |
|---|---|---|---|---|
| 1 | 세이지 | `#EDF2E9` | `#3F5334` | `#6E8F57` |
| 2 | 더스티 로즈 | `#F7EAEC` | `#6B3A42` | `#A96F7B` |
| 3 | 미스트 블루 | `#E8F0F5` | `#2F4A5C` | `#5E88A2` |
| 4 | 라벤더 | `#EFEBF5` | `#473F5C` | `#7C6FA2` |
| 5 | 클레이 | `#F7EBE4` | `#6B4632` | `#A87356` |
| 6 | 머스터드 | `#F5EFDF` | `#5E4C22` | `#997E38` |
| 7 | 올리브 | `#F0F1E3` | `#4C5230` | `#7B8349` |
| 8 | 티일 | `#E4F0EF` | `#2C4E4C` | `#558C88` |
| 9 | 플럼 | `#F3EAF1` | `#573C52` | `#8E6885` |
| 10 | 샌드 | `#F4EFE7` | `#5C4E3A` | `#93805F` |
| 11 | 슬레이트 | `#EAEDF3` | `#3A4459` | `#67738F` |
| 12 | 코랄 | `#F9EAE7` | `#6E3F36` | `#AF6E5E` |

**저장 방식**: DB의 `categories.color`에는 **팔레트 키**(`sage`, `mist` …)를 저장한다. hex를 저장하지 않는다.
→ 나중에 톤을 조정하거나 다크 모드를 추가할 때 데이터를 건드리지 않아도 된다.

**기본 배정**: 직장 = 미스트 블루(3) · 개인 = 세이지(1) · 가족 = 클레이(5)

**미분류**: 팔레트에 없는 중립 회색 (`#F2F3F4` / `#5B6169` / `#9AA0A6`). 실제 카테고리가 아니므로 색을 배정하지 않는다.

### 2.3 대비 규칙

| 조합 | 목표 |
|---|---|
| `--tx` on `--bg` (카드 본문) | ≥ 4.5:1 (WCAG AA) |
| `--dt` on 흰 배경 (달력 점) | ≥ 3:1 (UI 컴포넌트) |
| `--ink` on `--bg` | 항상 통과 |

**팔레트를 수정할 때는 이 세 값을 다시 측정한다.** 예쁘다는 이유로 밝게 바꾸면 조용히 깨진다.

### 4.2 세로 예산 (375 × 667, iPhone SE 기준)

| 영역 | 높이 | 비고 |
|---|---:|---|
| 헤더 | 44 | |
| 카테고리 밴드 | 36 | |
| 요일 행 | 20 | |
| 달력 6행 × 34 | 204 | **압축 셀** |
| 밀림 폴드 | 36 | 있을 때만 |
| 섹션 헤더 | 28 | |
| **리스트 가용** | **227** | |
| 입력 바 | 52 | 하단 고정 |
| 하단 세이프 에어리어 | 20 | |
| **합계** | **667** | |

**리스트 227px → 카드 3개** (카드 62 + 간격 7 = 69 × 3 = 207)

접었을 때(주간 모드): 달력 204 → 62 로 줄어 **142px 확보 → 카드 5개**

> **이 표가 시안 C의 안전장치다.** 새 요소를 넣기 전에 여기에 행을 추가해 합계가 667을 넘지 않는지 본다.

### 4.3 달력 셀 압축

| 항목 | 값 |
|---|---|
| 셀 높이 | **34px** (정사각형이 아님 — 세로를 줄인 직사각형) |
| 터치 타깃 | 폭 53 × 높이 34 = **44px 미만** ⚠️ |
| 보정 | 셀 주변 여백을 터치 영역에 포함해 실효 44px 확보 (`padding` 대신 `::after` 확장) |
| 점 | 지름 4.5px, 간격 2px, **최대 3개** + 초과 시 `+N` |
| 기간 막대 | 높이 4px, 셀 폭의 86%, 양 끝 셀만 라운드 |

## 5. 컴포넌트 명세

### 5.1 헤더

| | |
|---|---|
| 좌 | `2026년 8월` — 탭하면 월 선택 |
| 우 | `⚙` 설정 (계정 · PWA 안내 · 완료 숨기기 토글) |
| 오늘로 | 오늘이 아닌 달을 보고 있을 때만 `오늘` 버튼이 나타남 |

### 5.2 카테고리 밴드 ⭐

시안 C의 핵심. **세 가지 역할을 겸한다.**

```
[직장] [개인] [가족] [+]
  ↑      ↑            ↑
필터   길게 눌러 편집   추가
```

| 상태 | 표현 |
|---|---|
| 표시 중 | 카테고리 `--bg` 배경 + `--tx` 텍스트 |
| 숨김 (필터 OFF) | `--line-2` 배경 + `--ink-3` 텍스트 |
| 탭 | 필터 토글 (달력·리스트 동시 반영) |
| **길게 누르고 뗌** | 편집 시트 열림 → **색 편집 2탭 달성** (E4) |
| **길게 눌러 끌기** | 순서 이동 (F4-6) |
| `[+]` | 새 카테고리 |

**제스처 설계 — 길게 누르기 하나로 편집과 이동을 겸한다**

길게 누르기는 "집어 들기"까지만 하고, 그 뒤 **움직였는지 여부**로 두 동작을 가른다.

```
길게 누름 ─┬─ 움직이지 않고 뗌 → 편집 시트
           └─ 끌고 나서 뗌      → 순서 이동 (드롭 위치에 삽입)
```

편집 모드 진입 버튼이나 별도의 핸들을 만들지 않아도 되고, 둘 다 발견하기 쉽다.
집어 들기 전에 손가락이 움직이면 **가로 스크롤**로 판단해 길게 누르기를 취소한다.
끌려가는 칩은 확대 + 그림자, 나머지는 opacity 0.55로 낮춰 어느 것이 움직이는지 보이게 한다.

미분류 칩과 `[+]`는 이동 대상이 아니다.
| 넘칠 때 | 가로 스크롤. 스크롤바 숨김, 우측 페이드 |

### 5.3 달력

| 요소 | 규칙 |
|---|---|
| 오늘 셀 | `--ink` 배경 + 흰 글자 + 700. 점도 흰색 |
| 선택 셀 (오늘 아님) | 1.5px `--ink` 테두리 |
| 이전/다음 달 날짜 | `#C8CCD1` |
| 완료된 할일의 점 | 같은 색, `opacity: .35` |
| 필터로 숨긴 카테고리 | 점을 그리지 않음 |
| 월 전환 | 좌우 스와이프 + 헤더 탭 |
| **접기** | 달력 영역 위로 스와이프 → 주간 1행. 아래로 → 월간 복귀 |

**접기 상태는 기억하지 않는다.** 앱을 열면 항상 월간 + 오늘 (P2).

### 5.4 밀림 폴드 (E5)

| | |
|---|---|
| 표시 조건 | 오늘을 보고 있고, `endDate < 오늘 && !done` 인 항목이 1개 이상 |
| 기본 상태 | **접힘.** `⌄ 밀린 할일 3` 개수만 |
| 펼침 | 항목 리스트 + 각 항목에 `[오늘로]` |
| 지속형 | 대상에서 제외 |
| 우측 | 동기화 대기 표식 (있을 때만) — `--ink-3`, 11px |

### 5.5 할일 카드

```
┌──────────────────────────────────┐
│ ▢  3분기 캠페인 보고서            │   ← 13.5px / 500
│    직장 · 8/14까지                │   ← 10.5px / opacity .72
└──────────────────────────────────┘
   배경 --bg · 전체 텍스트 --tx
```

| 항목 | 규칙 |
|---|---|
| 배경 | 카테고리 `--bg` **전체** (좌측 테두리 방식 아님) |
| 카테고리 이름 | **항상 표시.** 색만으로 구분하지 않는다 (접근성 확정 사항) |
| 체크박스 | 16px, 좌측. `currentColor` 테두리 |
| 완료 | 취소선 + `opacity: .62` |
| 메타 — 마감형 | `직장 · 8/14까지` (하루짜리면 생략) |
| 메타 — 지속형 | `개인 · 12/31일` |
| 탭 | 상세 편집 시트 |
| 좌 스와이프 | 삭제 (확인 후) |
| 최소 높이 | 62px (44px 터치 타깃 여유 확보) |

**정렬**: 미완료 → 완료 순. 같은 그룹 안에서는 `sortOrder`. **지속형은 각 그룹의 끝**에 모은다 (매일 등장해 다른 할일을 밀어내지 않도록).

### 5.6 입력 바 (E1) ⭐

**닫힘 (기본)**

```
┌─────────────────────────────┐
│ ✎  할일 추가…            ⋯  │   52px
└─────────────────────────────┘
```

**열림 (탭 후)**

```
┌─────────────────────────────┐
│ [직장] [개인] ●가족          │  ← 카테고리 칩. 마지막 사용에 표시
│ ✎  어린이집 준비물|      ⋯  │
└─────────────────────────────┘
        ↑ 키보드
```

| 항목 | 규칙 |
|---|---|
| 위치 | 하단 고정. 키보드가 올라오면 그 위에 붙음 |
| 저장 | **Enter.** 저장 버튼 없음 |
| 저장 후 | **닫히지 않음.** 텍스트만 비우고 커서 유지 → 연속 입력 |
| 날짜 | 현재 선택된 날짜 (P6). 오늘이 아니면 플레이스홀더에 `8월 5일에 추가…` |
| 카테고리 | 마지막 사용이 선택된 상태. 칩 1탭으로 변경 |
| `⋯` | 상세 시트 (기간 · 매일 체크 · 메모) |
| 빈 Enter | 무반응. 에러 없음 |
| **IME** | `isComposing === true` 인 Enter는 **무시**. 이 장치의 성패가 여기 달렸다 |

### 5.7 상세 시트 (바텀 시트)

```
┌─────────────────────────────┐
│ 제목  [                   ] │
│ 카테고리  [직장][개인][가족] │
│ 날짜  [2026-08-03]          │
│ ─────────────────────────── │
│ 기간으로 설정         [OFF] │  ← 1단
│   종료일  [        ]        │     ON일 때만
│   매일 체크           [OFF] │  ← 2단, 기간 ON일 때만
│ ─────────────────────────── │
│ 메모  [                   ] │
│                             │
│  [삭제]              [저장] │
└─────────────────────────────┘
```

**2단 접기가 P5의 구현체다.** 기본 경로에서는 기간도 매일 체크도 보이지 않는다.

### 5.8 카테고리 편집 시트

```
┌─────────────────────────────┐
│ 이름  [가족            ]    │
│                             │
│ ● ● ● ● ● ●                │  ← 미사용 색 먼저
│ ● ● ● ● ● ●                │
│                             │
│ [삭제]               [완료] │
└─────────────────────────────┘
```

| 항목 | 규칙 |
|---|---|
| 색 탭 | **즉시 미리보기** — 뒤의 카드·달력이 바로 바뀜 (저장 대기 없음) |
| 취소 | 원래 색으로 복귀 |
| 색 정렬 | 아직 안 쓴 색 먼저, 쓰는 색은 뒤에 (체크 표시) |
| 자유 컬러피커 | **제공하지 않음** (P9) |
| 삭제 | 소속 할일 0개 → 즉시 / 1개 이상 → "미분류로 이동" ⁄ "함께 삭제" 선택 |

## 6. 인터랙션

### 6.1 체크 (E3)

```
0ms    탭
0ms    체크박스 채워짐 + 하프틱(가능하면)
0-250  카테고리 색이 카드 전체에 번짐 → opacity .62 로 정착
0-250  달력의 해당 점이 opacity .35 로 (동시)
250ms  취소선 완료
```

| | |
|---|---|
| 이징 | `cubic-bezier(.4, 0, .2, 1)` |
| 서버 | 기다리지 않는다. 낙관적 반영 후 큐 (요구사항 3.5) |
| 해제 | 같은 시간의 역방향 |
| 축소 모션 | `prefers-reduced-motion: reduce` → 애니메이션 없이 상태만 전환 |

**달력과 리스트가 같은 타이밍에 변하는 것이 핵심.** 둘의 연결을 눈으로 알려준다.

### 6.2 제스처

| 대상 | 동작 | 결과 |
|---|---|---|
| 달력 | 좌우 스와이프 | 이전/다음 달 |
| 달력 | 위로 스와이프 | 주간으로 접기 |
| 주간 스트립 | 아래로 스와이프 | 월간 펼치기 |
| 할일 카드 | 좌 스와이프 | 삭제 |
| 카테고리 칩 | 길게 누르기 | 편집 시트 |

### 6.3 빈 상태

| 상황 | 표현 |
|---|---|
| 첫 실행 (할일 0) | 달력은 그대로 · 리스트 자리에 **"오늘 할 일을 아래에 적어보세요"** + 입력 바로 시선 유도 |
| 특정 날짜에 할일 없음 | `할 일 없음` 한 줄. 일러스트 없음 |
| 카테고리 0개 | 밴드에 `[+ 카테고리 만들기]` 만 |

**샘플 할일을 넣지 않는다** (P12). 기본 카테고리 3개만으로 앱의 성격은 전달된다.

### 6.4 피드백

| 상황 | 표현 |
|---|---|
| 저장 성공 | **아무 표시도 하지 않는다.** 화면이 이미 바뀌었다 |
| 전송 대기 | 폴드 우측 `동기화 대기 N` — 조용히 |
| 최종 실패 | 하단 배너 + 화면 롤백. `--danger` |
| 삭제 | 확인 시트. 되돌리기 스낵바는 두지 않음 |

## 7. 반응형

| 구간 | 변화 |
|---|---|
| **375~767** | 기준 설계. 위 명세 그대로 |
| **768~1023** | 달력 셀 높이 34 → 52. 셀 안에 점 대신 **할일 제목 1줄** 표시. 리스트는 아래 유지 |
| **1024+** | 2열 — 좌측 달력(고정, 넓게) / 우측 카테고리 밴드 + 리스트 + 입력 바. 최대 폭 1120px 중앙 정렬 |

미디어 쿼리는 `min-width`만 쓴다. `max-width`로 되돌리지 않는다.

## 8. 접근성

| 항목 | 규칙 |
|---|---|
| 색 단독 의존 금지 | 카드에 카테고리 **이름 텍스트 항상 노출**. 모바일에서도 생략 없음 |
| 대비 | 카드 텍스트 4.5:1 / 달력 점 3:1 (2.3) |
| 터치 타깃 | 44×44px 이상. 달력 셀은 4.3의 보정 적용 |
| 키보드 | 달력 화살표 이동, `Enter` 날짜 선택, `Space` 체크 토글 |
| 스크린 리더 | 체크박스 `aria-checked` · 카드 `aria-label`에 "카테고리 · 제목 · 기간 · 완료 여부" |
| 달력 셀 | `aria-label="8월 3일, 할일 3개"` |
| 모션 | `prefers-reduced-motion` 존중 |
| 포커스 | 2px `--ink` 아웃라인. `:focus-visible`만 |
